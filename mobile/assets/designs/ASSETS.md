# Letter-design artwork: sources and licences

**Release gate OPEN-14 (DEC-061 (2)):** every file shipped in a production build must be original
or commissioned artwork, or come from a source whose licence permits use in the app, with the source
and licence recorded in this table. Generated placeholders must be replaced or explicitly cleared by
the owner first.

| File(s)                                                                                     | What                                                                                  | Source                                                                                           | Licence       | Status                      |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------- | --------------------------- |
| `papers/aged_cream.webp`, `papers/warm_ivory.webp`, `papers/parchment.webp`                 | Tileable paper textures (alpha overlay on the paper colour)                           | Procedurally generated by `tools/design-assets/generate_placeholders.py` (no third-party images) | Project-owned | **Provisional placeholder** |
| `papers/edge_ageing.webp`                                                                   | Edge browning overlay                                                                 | Same script                                                                                      | Project-owned | **Provisional placeholder** |
| `stamps/stamp_dove.webp`, `stamps/stamp_palm.webp`, `stamps/stamp_lighthouse.webp`          | Postage stamps (denominations only; no country or postal-authority names)             | Same script                                                                                      | Project-owned | **Provisional placeholder** |
| `stickers/sticker_flower.webp`, `stickers/sticker_moon.webp`, `stickers/sticker_washi.webp` | Stickers                                                                              | Same script                                                                                      | Project-owned | **Provisional placeholder** |
| `postmarks/postmark_round.webp`, `postmarks/postmark_wavy.webp`                             | Postmarks (the round one has an empty band; the app writes the letter's date into it) | Same script                                                                                      | Project-owned | **Provisional placeholder** |

Fonts are not stored here: they come from the `@expo-google-fonts/*` packages (Caveat, IM Fell English,
Playfair Display, Aref Ruqaa, Amiri, Reem Kufi, Cairo, Tajawal), all under the SIL Open Font
License 1.1, which permits bundling in an app.

Regenerate the placeholders from the repo root with `python tools/design-assets/generate_placeholders.py`
(Pillow + numpy). Keep the file names: they are the catalog keys in `shared/design-catalog.json`.
